# Projekti ülevaade

## Mis süsteem

**EPR** (Extended Producer Responsibility) on EL poliitika raamistik — direktiivid 2008/98/EÜ, 2012/19/EL, 2019/904 (SUP), määrused (EL) 2023/1542 (akumäärus), (EL) 2025/40 (PPWR), ELVR ettepanek COM(2023) 451.

**TVR** (Tootjavastutuse register) on Eesti infosüsteem, mis EPR-kohustusi registreerib ja täitmist jälgib.

GitHub org'is on projekti nimi "Extended Producer Responsibility (EPR)". Igapäevases jutus kasutame mõlemat terminit:
- **EPR** = kohustused, poliitika (nt "EPR volitatud esindaja", "EPR kohustus")
- **TVR** = Eesti süsteem, mida me ehitame
